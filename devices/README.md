# devices.json

The shared database of battery recipes for Islet — how to ask a device for its charge.
Islet fetches this file once a day, so a merged recipe reaches everyone without a new release.

How to write and test a recipe: [docs/devices.md](../docs/devices.md) · [по-русски](../docs/devices.ru.md).

Recipes only ask for state; every pull request is reviewed by hand.
