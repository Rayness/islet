# Kawaki Island

Островок у верхнего края экрана Windows: поиск по приложениям и файлам и кнопки
для быстрого запуска. Это отдельное десктопное приложение, от сайта Kawaki оно не
зависит.

## Как пользоваться

- **Свёрнут.** Тонкая полоска по центру у верхнего края.
- **Навести курсор.** Островок раскрывается, фокус остаётся в том окне, где ты работал.
  Если увести курсор, он свернётся обратно.
- **Ctrl + Alt + Пробел.** Островок раскрывается сразу с курсором в поиске. Если нажать
  ещё раз или Esc, он свернётся, а фокус вернётся в прежнее окно.
- **Поиск.** Сначала ищет приложения из «Все приложения», затем файлы и папки из индекса
  Windows Search, последней строкой предлагает поиск в интернете.
  - ↑/↓ выбирают результат, Enter открывает его.
  - Ctrl+Enter показывает файл в папке.
  - Правый клик по результату открывает меню: «Показать в папке», «Закрепить на островке».
- **Кнопки слева.** Проводник, Терминал, Параметры, Диспетчер задач и Kawaki.
  Правый клик по кнопке открепляет её. Всего кнопок может быть не больше шести.
- **Меню «…».** Здесь включается автозапуск, открывается `pins.json` на правку, кнопки
  возвращаются к стандартным и закрывается островок.
- Если на том же мониторе открыта игра или видео во весь экран, островок прячется.

## Данные

`%LOCALAPPDATA%\KawakiIsland\`:

- `pins.json`: закреплённые кнопки. Файл можно править руками, изменения подхватятся
  при следующем раскрытии островка. Поле `kind` принимает значения:
  - `app`: приложение по его id из shell:AppsFolder;
  - `path`: файл, папка или exe, переменные окружения вроде `%WINDIR%` раскрываются;
  - `url`: ссылка или протокол (`https://`, `ms-settings:`).
- `island.log`: смены состояний и ошибки поиска.

## Сборка

Нужен .NET 10 SDK. Visual Studio не обязательна.

```powershell
dotnet build src/KawakiIsland/KawakiIsland.csproj -c Debug
src/KawakiIsland/bin/Debug/net10.0-windows10.0.22621.0/win-x64/KawakiIsland.exe
```

- Стек: WinUI 3 (Windows App SDK 1.8), без упаковки в MSIX.
- Сборка self-contained: Windows App Runtime отдельно ставить не нужно.

## Устройство

| Где | Что |
|---|---|
| `IslandWindow.xaml(.cs)` | окно: три состояния (свёрнут / наведение / закреплён), пилюля с анимацией внутри прозрачного окна, клавиатура |
| `Native/` | Win32: прозрачное безрамочное окно поверх всех (стиль, WM_NCCALCSIZE, blur-behind + прозрачный backdrop), горячая клавиша, детектор полноэкранных окон |
| `Search/` | индекс приложений (Shell.Application → shell:AppsFolder), файлы через OLE DB к Windows Search |
| `Shell/` | иконки оболочки (IShellItemImageFactory на отдельном STA-потоке), запуск, автозапуск |
| `Pins/` | закреплённые кнопки и их хранение |
