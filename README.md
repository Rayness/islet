# Kawaki Island

Островок у верхнего края экрана Windows: поиск по приложениям и файлам на всех
дисках и кнопки для быстрого запуска. Это отдельное десктопное приложение, от сайта
Kawaki оно не зависит.

## Как пользоваться

- **Свёрнут.** Тонкая капсула по центру у верхнего края.
- **Навести курсор.** Островок раскрывается, фокус остаётся в том окне, где ты работал.
  Если увести курсор, он свернётся обратно.
- **Горячая клавиша** (по умолчанию Ctrl + Alt + Пробел). Островок раскрывается сразу
  с курсором в поиске. Если нажать ещё раз или Esc, он свернётся, а фокус вернётся
  в прежнее окно.
- **Поиск.** Сначала приложения, затем файлы и папки, последней строкой — поиск
  в интернете. Файлы берутся из двух источников:
  - индекс Windows Search (пользовательские папки на системном диске);
  - собственный индекс островка для остальных дисков и папок из настроек.
- **Клавиши в выдаче.** ↑/↓ выбирают результат, Enter открывает его, Ctrl+Enter
  показывает файл в папке. Правый клик по результату открывает меню:
  «Показать в папке», «Закрепить на островке».
- **Кнопки слева.** До шести штук. Правый клик по кнопке открепляет её.
- **Меню «…».** Открывает настройки и закрывает островок.
- Если на том же мониторе открыта игра или видео во весь экран, островок прячется.

## Настройки

| Раздел | Что внутри |
|---|---|
| Общие | горячая клавиша (запись сочетания), автозапуск, поисковик для строки «в интернете» |
| Внешний вид | стекло, плотность фона, ширина островка, часы |
| Поиск | индекс дисков вкл/выкл, состояние и переиндексация, список папок, исключения, ссылка на параметры поиска Windows |
| Кнопки | порядок, удаление, добавление программы, файла, папки или ссылки |

## Данные

`%LOCALAPPDATA%\KawakiIsland\`:

- `settings.json`: настройки;
- `pins.json`: кнопки, файл можно править руками;
- `drive-index.bin`: кеш индекса дисков, пересобирается раз в сутки и при смене папок;
- `island.log`: смены состояний и ошибки поиска.

## Сборка

Нужен .NET 10 SDK. Visual Studio не обязательна.

```powershell
dotnet build src/KawakiIsland/KawakiIsland.csproj -c Debug
src/KawakiIsland/bin/Debug/net10.0-windows10.0.22621.0/win-x64/KawakiIsland.exe
```

- Стек: WinUI 3 (Windows App SDK 1.8) и Win2D (только описание эффекта стекла),
  без упаковки в MSIX, self-contained.
- Ключи для проверки вида без клавиатуры и мыши:
  - `--demo <запрос>` раскрывает островок с запросом, не забирая фокус;
  - `--settings [general|look|search|pins|about]` открывает окно настроек на нужном разделе.

## Устройство

| Где | Что |
|---|---|
| `IslandWindow.xaml(.cs)` | островок: три состояния (свёрнут / наведение / закреплён), пилюля с анимацией внутри прозрачного окна, клавиатура |
| `SettingsWindow.xaml(.cs)` | окно настроек, каждое изменение сохраняется сразу |
| `Settings/` | модель настроек и `SettingsStore` с событием `Changed` |
| `Native/WindowHost.cs` | перехват сообщений окна: горячая клавиша, срез системной рамки (`WM_NCCALCSIZE`, `WM_NCACTIVATE`, `WM_STYLECHANGING`) |
| `Native/IslandBackdrop.cs` | подложка: размытый рабочий стол (HostBackdropBrush), вырезанный маской по форме пилюли |
| `Search/DriveIndex.cs` | индекс имён файлов: общий буфер символов, параллельный поиск, кеш на диске, FileSystemWatcher |
| `Search/` (остальное) | индекс приложений (shell:AppsFolder), файлы через OLE DB к Windows Search |
| `Shell/` | иконки оболочки, запуск, автозапуск |
| `Pins/` | кнопки и их хранение |
