# Islet

Островок у верхнего края экрана Windows: поиск по приложениям и файлам на всех дисках
и кнопки для быстрого запуска. Свёрнутый — тонкая капсула шириной в пару сантиметров;
наводишь курсор или жмёшь горячую клавишу — раскрывается в строку поиска.

Отдельное десктопное приложение на WinUI 3. Без установщика, без службы, без учётной
записи: один exe, настройки рядом в `%LOCALAPPDATA%`.

> Интерфейс приложения на русском языке.

## Что умеет

- **Поиск по приложениям** — всё из `shell:AppsFolder`, включая приложения из Store.
- **Поиск по файлам на всех дисках.** Windows Search индексирует только пользовательские
  папки на системном диске; Islet поверх этого держит собственный индекс имён для
  остальных дисков, так что файл на `D:` находится так же быстро, как на рабочем столе.
- **Поиск в интернете** последней строкой выдачи: Яндекс, Google, Bing или DuckDuckGo.
- **Кнопки быстрого запуска** — до шести штук: программа, файл, папка или ссылка.
- **Не мешает.** Островок не забирает фокус: раскрылся по наведению — курсор и каретка
  остались в том окне, где ты работал. Если на том же мониторе игра или видео во весь
  экран, островок прячется.
- **Стекло.** Подложка — размытый рабочий стол, вырезанный по форме капсулы; плотность
  тонировки настраивается, эффект можно выключить.

## Установка

Готовых сборок пока нет — собирается из исходников.

```powershell
git clone https://github.com/Rayness/islet.git
cd islet
dotnet publish src/Islet/Islet.csproj -c Release -r win-x64 --self-contained
```

Готовое приложение окажется в `src/Islet/bin/Release/net10.0-windows10.0.22621.0/win-x64/publish/`.
Папку можно положить куда угодно и запускать `Islet.exe` оттуда; автозапуск включается
в настройках, он прописывает путь к текущему exe в `HKCU\...\Run`.

Для сборки нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0),
Visual Studio не обязательна. Ключ `--self-contained` кладёт рядом и сам .NET — без него
на машине понадобится .NET 10 Desktop Runtime. Windows App SDK всегда едет внутри
сборки, отдельно ставить его не нужно.

Вместо `win-x64` можно указать `win-arm64`.

## Как пользоваться

Островок живёт в трёх состояниях:

| Состояние | Как попасть | Что происходит |
|---|---|---|
| Свёрнут | состояние по умолчанию | тонкая капсула по центру верхнего края, поверх окон |
| Наведение | подвести курсор | раскрывается, фокус остаётся в прежнем окне; увёл курсор — свернулся |
| Раскрыт | горячая клавиша, по умолчанию `Ctrl + Alt + Пробел` | раскрывается с курсором в строке поиска; ещё раз или `Esc` — свернётся и вернёт фокус туда, откуда забрал |

В выдаче:

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | выбрать результат |
| `Enter` | открыть |
| `Ctrl + Enter` | показать файл в папке |
| `Esc` | свернуть островок |

Правый клик по результату открывает меню: «Показать в папке», «Закрепить на островке».
Правый клик по кнопке слева — открепить её. Кнопка «…» справа открывает настройки
и позволяет закрыть островок.

## Как устроен поиск

Результаты идут в порядке: приложения → файлы и папки → строка «искать в интернете».
Файлы приходят из двух источников сразу:

- **Windows Search** — через OLE DB к системному индексу. Быстро и с учётом содержимого,
  но покрывает только то, что индексирует сама Windows: обычно пользовательские папки
  на системном диске.
- **Собственный индекс дисков** — обход несистемных дисков (или списка папок из настроек)
  с запоминанием имён файлов. Индекс лежит одним бинарным файлом, перечитывается при
  запуске, пересобирается раз в сутки и при смене списка папок; изменения на диске
  между обходами ловит `FileSystemWatcher`. Поиск по нему идёт параллельно по общему
  буферу символов, без аллокаций на каждое имя.

Индекс дисков можно выключить в настройках — тогда останется только Windows Search.

## Настройки

| Раздел | Что внутри |
|---|---|
| Общие | горячая клавиша (записывается нажатием), автозапуск с Windows, поисковик для строки «в интернете» |
| Внешний вид | стекло, плотность фона, ширина островка (560–960 px), часы |
| Поиск | индекс дисков вкл/выкл, его состояние и переиндексация, список папок, исключения, ссылка на параметры поиска Windows |
| Кнопки | порядок, удаление, добавление программы, файла, папки или ссылки |

Каждое изменение сохраняется сразу, закрывать окно настроек не нужно.

## Данные

Всё лежит в `%LOCALAPPDATA%\Islet\`:

| Файл | Что это |
|---|---|
| `settings.json` | настройки |
| `pins.json` | кнопки; файл можно править руками, островок перечитает его |
| `drive-index.bin` | кеш индекса дисков; можно удалить, соберётся заново |
| `island.log` | смены состояний и ошибки поиска, не больше 512 КБ |

Приложение ничего не отправляет по сети: единственный выход наружу — когда ты сам
выбираешь строку «искать в интернете» или открываешь кнопку-ссылку.

## Требования

- Windows 10 версии 2004 (сборка 19041) или новее, x64 либо ARM64.
- Для сборки — .NET 10 SDK.

## Устройство

| Где | Что |
|---|---|
| `IslandWindow.xaml(.cs)` | островок: три состояния, капсула с анимацией внутри прозрачного окна, клавиатура и выдача |
| `SettingsWindow.xaml(.cs)` | окно настроек |
| `Settings/` | модель настроек и `SettingsStore` с событием `Changed` |
| `Native/WindowHost.cs` | перехват сообщений окна: горячая клавиша, срез системной рамки (`WM_NCCALCSIZE`, `WM_NCACTIVATE`, `WM_STYLECHANGING`) |
| `Native/IslandBackdrop.cs` | подложка: размытый рабочий стол (`HostBackdropBrush`), вырезанный маской по форме капсулы |
| `Search/DriveIndex.cs` | индекс имён файлов: общий буфер символов, параллельный поиск, кеш на диске, `FileSystemWatcher` |
| `Search/AppIndex.cs`, `FileSearch.cs` | приложения из `shell:AppsFolder`, файлы через OLE DB к Windows Search |
| `Shell/` | иконки оболочки, запуск чего угодно, автозапуск |
| `Pins/` | кнопки и их хранение |

Стек: WinUI 3 (Windows App SDK 1.8), .NET 10, Win2D — только ради описания эффекта
стекла. Упаковки в MSIX нет.

## Разработка

```powershell
dotnet build src/Islet/Islet.csproj -c Debug
src/Islet/bin/Debug/net10.0-windows10.0.22621.0/win-x64/Islet.exe
```

Два ключа командной строки, чтобы смотреть на вид без клавиатуры и мыши:

- `--demo <запрос>` — раскрыть островок с готовым запросом, не забирая фокус;
- `--settings [general|look|search|pins|about]` — открыть настройки на нужном разделе.

Запущен всегда один экземпляр: второй запуск завершается сразу.
