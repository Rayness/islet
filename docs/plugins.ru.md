# Плагины для Islet

**English: [plugins.md](plugins.md)**

Плагин — это папка с файлом `plugin.json`. Положи папку в `%APPDATA%\Islet\plugins`, открой
*Настройки → Плагины* и нажми **Перезагрузить**. Это вся установка.

Плагины бывают трёх видов, и в одной папке их можно смешивать:

| Вид | Что пишешь | Для чего |
|---|---|---|
| Ярлыки | пару адресов-шаблонов в `plugin.json` | `gh islet` → поиск на GitHub |
| Строки | готовые строки выдачи в `plugin.json` | команды: открыть файл, папку, сайт, скопировать заготовку |
| Процесс | программу на любом языке, которая говорит JSON через stdin/stdout | всё, где нужен код: живые данные, расчёты, запросы к API |

С Islet приходят два плагина, их удобно читать как образцы:
[`plugins/web-shortcuts`](../plugins/web-shortcuts/plugin.json) (только ярлыки) и
[`plugins/process-killer`](../plugins/process-killer) (процессный, на PowerShell).
[`docs/examples/python-passwords`](examples/python-passwords) использует весь протокол целиком.

Плагин в `%APPDATA%\Islet\plugins` с тем же `id`, что у встроенного, заменяет встроенный.

## plugin.json

Комментарии и лишние запятые разрешены. Любое текстовое поле — либо строка, либо объект с
переводами: `"name": { "en": "Passwords", "ru": "Пароли" }`. Islet берёт язык интерфейса,
потом английский.

```jsonc
{
  "id": "passwords",                 // уникальный и неизменный между версиями
  "name": { "en": "Passwords", "ru": "Пароли" },
  "version": "1.0.0",
  "author": "Ты",
  "description": "«pw 24» — надёжный пароль",
  "icon": "\uE8D7",                  // глиф Segoe Fluent Icons или картинка из папки: "icon.png"
  "api": 1,                          // версия протокола, под которую писали

  // Процессный плагин
  "keywords": ["pw"],                // «pw » в строке поиска — искать только здесь
  "global": false,                   // отвечать и без ключевого слова (тогда быстро!)
  "answersEmpty": true,              // отвечать на «pw » без текста после него
  "order": 60,                       // место группы в общей выдаче; встроенные — 0…100
  "maxResults": 8,
  "timeoutMs": 1500,                 // ответ позже — выбрасывается
  "startup": false,                  // запускать процесс вместе с островком (для фоновых уведомлений)
  "run": { "command": "python", "args": ["main.py"] },

  // Строки без кода
  "items": [
    {
      "title": { "en": "Open the project", "ru": "Открыть проект" },
      "subtitle": "D:\\Work\\islet",
      "keywords": "работа islet репо",       // дополнительные слова для поиска, через пробел
      "glyph": "\uE8B7",
      "action": { "open": "D:\\Work\\islet" },
      "confirm": null                        // текст «нажмите Enter ещё раз», если действие опасное
    }
  ],

  // Ярлыки: «gh запрос» → поиск по сайту
  "shortcuts": [
    { "keyword": "gh", "aliases": ["гх"], "name": "GitHub",
      "url": "https://github.com/search?q={query}",
      "home": "https://github.com",          // открывается на пустое «gh »
      "glyph": "\uE943" }
  ]
}
```

`run.command` ищется сначала в папке плагина, потом в `PATH`: работают и `"python"`, и
`"tool.exe"`, лежащий рядом с `plugin.json`. В `args` подстрока `{pluginDir}` заменяется на
папку плагина с обратной косой чертой в конце. Рабочая папка процесса — папка плагина.

## Действия

У строк, уведомлений и живых активностей есть действие. Одно из:

| Действие | Что происходит |
|---|---|
| `{"open": "…", "args": "…"}` | открыть файл, папку, адрес или протокол (`ms-settings:`), как это делает Windows |
| `{"reveal": "C:\\…\\file"}` | показать файл в папке |
| `{"app": "Microsoft.WindowsTerminal_8wekyb3d8bbwe!App"}` | запустить приложение из `shell:AppsFolder` |
| `{"copy": "текст"}` | скопировать; островок свернётся и вернёт фокус |
| `{"paste": "текст"}` | вставить текст в окно, где человек был до островка |
| `{"query": "pw 32"}` | подставить новый запрос, островок остаётся открытым |
| `{"invoke": "id", "data": {…}}` | прислать процессу `{"type":"invoke","action":"id","data":{…}}` |

Строка вместо объекта — это `open`. После `invoke` островок сворачивается; `"keepOpen": true`
в `data` оставляет его открытым (например, после удаления строки, чтобы запрос выполнился заново).

## Протокол процесса

Islet запускает `run.command` один раз — на первый запрос или сразу при `startup: true` — и
держит процесс живым. Сообщения — объекты JSON, **по одному на строку**, UTF-8, в обе стороны.
В stdout не пиши ничего, кроме сообщений; stderr копируется в лог Islet (первые 50 строк за
запуск) — им удобно отлаживаться.

Переменные окружения: `ISLET_API=1`, `ISLET_PLUGIN_DIR`, `ISLET_PIPE` (см. [protocol.md](protocol.md)),
`PYTHONIOENCODING=utf-8`, `PYTHONUNBUFFERED=1`.

### От Islet

```json
{"type":"hello","api":1,"islet":"0.2.0","language":"ru","pluginDir":"C:\\…\\passwords\\"}
{"type":"query","id":7,"text":"24","scoped":true}
{"type":"invoke","action":"batch","data":{"length":24}}
{"type":"shutdown"}
```

- `query.text` — то, что после ключевого слова; `scoped: false` — запрос из общей выдачи к
  плагину с `global: true`.
- На каждый запрос отвечай с тем же `id`. Islet спрашивает на каждой паузе в наборе и сам
  выбрасывает ответы на старые `id` — ничего отменять не нужно.
- После `shutdown` у процесса 300 мс, потом его завершат.

### В Islet

```jsonc
// Ответ на запрос
{"type":"results","id":7,"items":[
  {
    "id": "stable-id",                // необязательно; строка не прыгает между ответами
    "title": "k8#Vq…",
    "subtitle": "24 символа",
    "trailing": "Enter — копировать", // мелкая подпись справа
    "glyph": "\uE8D7",                // или "icon": "https://…" / "icon.png" / "iconPath": "C:\\…\\app.exe"
    "confirm": null,                  // попросить второй Enter перед действием
    "action": {"copy": "k8#Vq…"},
    "actions": [                      // пункты контекстного меню
      {"title": "Вставить", "glyph": "\uE77F", "action": {"paste": "k8#Vq…"}}
    ]
  }
]}

// Уведомление: островок раскрывается пиком, потом оно уходит в колокол
{"type":"notify","title":"Сборка готова","body":"42 с","glyph":"\uE930","action":{"open":"C:\\out"}}

// Живая активность в свёрнутой капсуле; прислать ещё раз — обновить, clear — убрать
{"type":"activity","id":"build","text":"Сборка 40%","progress":0.4,"color":"#3BE5CE"}
{"type":"activity","id":"build","clear":true}

// Строка в лог Islet
{"type":"log","message":"кеш прогрет"}
```

`notify`, `activity` и `log` можно слать когда угодно, не только в ответ на запрос. Для этого
и нужен `startup: true`: плагин следит за чем-то и сообщает об этом на островке.

### Как не мешать

- **Отвечай быстро.** Запрос в своей области ждёт до `timeoutMs`; `global` соревнуется с
  приложениями и файлами — держи его сильно быстрее 100 мс или не включай вовсе.
- **Падать можно, зацикливаться — нет.** Упавший процесс поднимется на следующий запрос
  (не чаще раза в пять секунд). Три падения за минуту выключают плагин с ошибкой в настройках
  до следующей перезагрузки плагинов.
- Живые активности исчезают, когда процесс завершился или плагин выключили.

### PowerShell

Windows PowerShell читает перенаправленный stdin в кодировке консоли. Начни скрипт с

```powershell
$utf8 = [System.Text.UTF8Encoding]::new($false)
[Console]::InputEncoding = $utf8
[Console]::OutputEncoding = $utf8
```

и сохрани `.ps1` в UTF-8 **с BOM** — иначе кириллица в самом скрипте превратится в кашу.

## Проверка

1. `plugin.json` читается (если нет — ошибка на карточке плагина в настройках).
2. Ключевое слово не совпадает со встроенными — наберите в островке `?`, там список.
3. Процесс отвечает на запрос из консоли:
   `echo {"type":"query","id":1,"text":"x","scoped":true} | python main.py`.
4. *Настройки → Плагины → Перезагрузить*, потом ключевое слово и пробел.
